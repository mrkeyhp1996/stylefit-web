# 🎵 StyleFit Web & Ghép Nhạc Tự Động

Hệ sinh thái Website và Công cụ đồng bộ âm thanh video nhảy tự động cho **StyleFit Step Dance Fitness** (Hải Phòng).

## Tính năng chính
1. **Ghép Nhạc Tự Động:** Tự động bắt nhịp loa phòng tập và căn khớp chuẩn mili-giây với bản nhạc gốc.
2. **Không nén mờ hình ảnh:** Giữ nguyên 100% luồng hình ảnh gốc (`-c:v copy`).
3. **Chạy 100% trên trình duyệt:** Không tốn chi phí máy chủ, bảo mật riêng tư cho người dùng.
4. **Chuẩn thương hiệu StyleFit:** Nhận diện màu cam `#FE7409` & đen viền theo phong cách Dark Luxury Fitness.
